# HEISSKRAFT — Прототип главной страницы

Рабочий HTML/CSS/JS прототип главной страницы сайта по дизайну из Figma  
(файл: HK-new-web, node `12:505`).

## Как открыть

Просто откройте `index.html` в браузере (двойной клик или через Live Server).

```bash
# или локальный сервер
cd heisskraft-prototype
python3 -m http.server 8080
# → http://localhost:8080
```

## Что реализовано

- **Header**: логотип, гамбургер-меню (мобильное), телефон, иконка звонка, поиск
- **Hero**: фоновое изображение Лахта-центра, заголовок, точки-слайдера, CTA-кнопка
- **Профили** (4 карточки): Подрядчик / Проектировщик / Частное лицо / Партнёр
- **Каталог** (6 карточек): Полный каталог, Водоснабжение, Отопление, Канализация/Дренаж, Пожаротушение, Водоподготовка
- **Footer**: 3 колонки + копирайт + логотип
- **Интерактив**:
  - Открытие/закрытие мобильного меню
  - Модальное окно поиска (Esc / клик вне)
  - Toast-уведомления при клике на карточки и ссылки (заглушки для дальнейшей доработки)
  - Hover-эффекты, focus-visible, адаптив (desktop → tablet → mobile)
  - Плавный скролл к якорям

- Шрифт: Inter (Extra Bold / Bold / Regular)
